# 数据说明

`CKSV站点坐标数据.csv` 为 GNSS 处理软件导出的站点坐标时间序列，同一份数据也以
`CKSV站点坐标数据.xlsx` 形式提供（内容一致，程序只读取 CSV）。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 站点 | CKSV（台湾） |
| 时间范围 | 2022-01-01 – 2026-05-28（十进制年 2022.0014 – 2026.4038） |
| 历元数 | 1530（日采样，个别缺测，最大间隔约 14 天） |
| 坐标单位 | 米（程序内部统一换算为毫米） |
| 编码 | UTF-8 with BOM |

## 主要字段

| 字段 | 说明 |
| --- | --- |
| `site` | 站点名 |
| `yyyy.yyyy` | 十进制年时间标签 |
| `__MJD` | 简化儒略日 |
| `__east(m)` / `_north(m)` / `____up(m)` | 东 / 北 / 天顶方向坐标修正量（m） |
| `_e0(m)` / `____n0(m)` / `u0(m)` | 对应方向的参考值（m） |
| `sig_e(m)` / `sig_n(m)` / `sig_u(m)` | 形式中误差（m） |
| `__corr_en` / `__corr_eu` / `__corr_nu` | 分量的相关系数 |
| `_latitude(deg)` / `_longitude(deg)` / `__height(m)` | 测站经纬度与大地高 |

> 注：`_longitude(deg)` 为 −239.78，等价于 120.22°E（导出软件以 360° 环绕表示）。

## 使用约定

- 加载时自动处理 BOM、全空行与重复历元；
- 坐标由米换算为毫米，并以首个历元（或全序列均值）为参考归零，得到相对形变；
- 时间筛选默认使用全部历元，可通过 `--year-range` 指定区间。
